APBD_01

Opis projektu

Prosta aplikacja konsolowa napisana w języku C# z wykorzystaniem platformy .NET.

Program wyświetla komunikat powitalny „Hello, APBD!” oraz oblicza sumę liczb z tablicy { 2, 4, 6 }.

Struktura projektu
Program.cs – główny plik aplikacji.
Greeting.cs – klasa odpowiedzialna za komunikat powitalny.
StatisticsHelper.cs – klasa obliczająca sumę liczb.
